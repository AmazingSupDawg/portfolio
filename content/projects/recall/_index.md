### Developer Notes
This was simply a project to explore the integration of Apple Intelligence, while creating just a solid app for studying (I had taken a biology class that was very studying heavy).
It went a lot further though, especially managing model availability and learning to adopt liquid glass with best HIG practices.

>Note: Development was supplemented through use of generative AI tools. All code was reviewed, and was mainly used to skeleton basic UI and accelerate bug fixing.
